# AI Proofreading Tool (AI校正ツール)

ローカル環境で動作する、小説執筆向けのAI校正アプリケーションです。
外部のAI（OpenAI API等）を利用して、誤字脱字、慣用句の誤用、表記ゆれなどを検出し、ユーザーが個別に「適用/無視」を選択できるUIを提供します。

## 特徴
- **誤字脱字・誤用検出**: 文脈を考慮したAIによる指摘。
- **セキュアな設計**: APIキーはブラウザのメモリ内にのみ保存され、外部サーバ（校正API以外）には送信されません。
- **パッチ適用形式**: AIが勝手に文章を書き換えるのではなく、指摘箇所の承認制を採用。
- **モダンなUI**: 執筆に集中できるシンプルなデザイン。

## 使い方

1. **セットアップと起動**:
   
   **バックエンド (Python)**:
   ```bash
   # 依存関係のインストール
   pip install -r backend/requirements.txt
   
   # spaCyモデルのダウンロード
   python -m spacy download ja_core_news_sm
   
   # サーバー起動 (別ターミナルで実行)
   python backend/main.py
   ```
   バックエンドは `http://localhost:8000` で起動します。

   **フロントエンド (Node.js)**:
   ```bash
   # 依存関係のインストール
   npm install

   # 開発サーバー起動
   npm run dev
   ```
   ブラウザで `http://localhost:5173` を開きます。

2. **設定**:
   - 画面右上の設定アイコン（歯車）をクリックします。
   - OpenAIのAPIキー（`sk-...`）を入力します。

3. **校正**:
   - エディタに小説の本文を入力・貼り付けます。
   - 「校正開始」ボタンを押します。

4. **確認と修正**:
   - 右側のパネルに指摘リストが表示されます。
   - 各指摘にマウスを合わせると、本文の該当箇所がハイライトされます。
   - **適用（チェックマーク）**: 指摘内容を本文に反映します。
   - **無視（×マーク）**: 指摘をリストから削除します。

## 技術スタック
- Frontend: React 19, Vite, Tailwind CSS
- AI Logic: OpenAI SDK

## 注意事項
- AIの指摘は必ずしも正しいとは限りません。最終的な判断は執筆者自身で行ってください。
